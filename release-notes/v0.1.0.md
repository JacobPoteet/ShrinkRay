The first ShrinkRay release. It re-encodes a TV show from H.264 to H.265 on an NVIDIA GPU and puts each new file back under the original filename.

This is an early build, and it can replace your originals. Setup offers a trial run that keeps them and stops after one episode. Start there.

## Highlights

- Replaces an original only after the new file passes every check: duration, stream counts, a full decode, and a saving of at least 15 percent.
- Keeps the filename and the container, so an `.mp4` stays `.mp4` and an `.mkv` stays `.mkv`. Plex keeps your metadata and watch history.
- Journals each swap. After a crash or power cut, the next start puts the files back in a safe state.
- Encodes and checks in a local scratch folder. Your library receives only a finished, checked file.

## New

- First-run setup that finds your tools, asks for your library and scratch folder, and gives a short tour.
- Choose a show from your library or drop a show folder on the window. ShrinkRay skips episodes already in H.265 and estimates the space you will get back.
- A recommended quality setting for each show, which you can change.
- Pause, skip, stop, or stop after the current episode. You can limit encoding to set hours.
- A tray icon, a running total of space saved, and a choice of screen color and case color.
- One running copy: starting ShrinkRay again brings the open window forward.

## What you need

- Windows 10 or 11, 64-bit.
- An NVIDIA GPU with HEVC NVENC.
- HandBrakeCLI, ffmpeg and ffprobe. Setup shows the `winget install` command for a missing tool.

## Install

Run `ShrinkRay-Setup-0.1.0.exe`, which installs for your user without an admin prompt, or unzip the `.zip` and run `ShrinkRay.exe`. Both include .NET. The files are unsigned, so Windows SmartScreen may warn you: choose **More info**, then **Run anyway**.

## Watch for

- Lossless audio such as FLAC, TrueHD and DTS-HD MA becomes AAC. AAC, AC3, E-AC3, DTS and MP3 tracks are copied.
- In `.mp4` files, picture-based subtitle tracks are dropped. Text subtitles stay.

## Known issues

- After you switch to the Graphite case, switches in the service panel may look off while they are on, including **Replace after checks pass**. Test renders drew them correctly on Beige. ([#48](https://github.com/JacobPoteet/ShrinkRay/issues/48))
- Logging off or shutting down Windows ends a run without asking. The next start cleans up. ([#31](https://github.com/JacobPoteet/ShrinkRay/issues/31))
- With the green screen color, the Active and Checked lamps look alike. ([#7](https://github.com/JacobPoteet/ShrinkRay/issues/7))
